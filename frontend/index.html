Imposes a strict global linear ordering function F: R → ℕ on all resource classes. A process may only request resource class R_k if and only if F(R_k) > max { F(R_i) | P holds R_i }. info Operating Systems Architecture Note: Termination vs Preemption

In non-shareable hardware resources (e.g. dedicated spoolers, tape drives, physical mutexes), forced resource preemption without checkpointing leaves shared states corrupted. As established in Phase 5 specifications, process termination is the safer, standard primary recovery mechanism. Preemption requires rollbacks, transaction undo logs, and anti-starvation timestamp aging mechanisms.
